
# Todo List 

A simple and responsive Todo List application built with HTML, CSS, and JavaScript.

This project allows users to add tasks and save them in the browser using LocalStorage, so the tasks remain available after refreshing the page.

---

## Features

- Add new tasks
- Display tasks dynamically
- Prevent adding empty tasks
- Store tasks in LocalStorage
- Load saved tasks when the page opens
- Responsive and mobile-first design
- Clean and simple user interface

---

## Technologies Used

- HTML
- CSS
- JavaScript
- DOM Manipulation
- LocalStorage
- JSON
